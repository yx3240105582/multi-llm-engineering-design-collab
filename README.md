# 多模型协作完成机电装备设计

本仓库记录了一次关于“多个大模型如何协作完成复杂机电装备设计项目”的完整讨论，以及在讨论中逐步收敛出的工作流程。

## 内容

- `docs/discussion-log.md` —— 完整对话记录（12 轮，含提问、追问、反驳与全部未解决的问题）

## 讨论涉及的要点

- 模型间交接：**接口约定**与**接口数值**为什么必须分离
- 验收权归谁：下游当闸门时的利益冲突与能力错配
- 多模型冗余与交叉验证：实证支持到什么程度
- 效率度量：完成度 / token / 时间，以及“人的修补免费”带来的反向激励
- 遗留问题：账本无校验、缺判分基准（oracle）、误差口径会反向激励

## 性质说明

这是**设计论证**阶段的记录，不是实验结论：它能说明“这套机制允许减误差发生”，不能说明“它确实减了误差”。文中文献引用均为可核查的 arXiv 编号，结论性判断带有可靠度标注。

## 讨论的起点与终点

起点：如何让多个大模型协作完成一个复杂工程项目。
终点：一套五阶段流程（初始化 → 需求分解 → 设计 → 工作 → 评估）+ 两条度量口径上的自我约束（只计模型侧成本；完成度在人修补前评定）。
